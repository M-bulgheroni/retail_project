# Proyecto Retail

Base de datos desarrollada en PostgreSQL como parte de la pre-entrega de SQL.

## Tablas

El proyecto contiene las siguientes tablas:

- clientes
- productos
- ventas

Las tablas incluyen claves primarias, claves foráneas y restricciones de integridad.

## Cómo ejecutar

1. Crear la base de datos `retail_project`.
2. Conectarse a la base de datos utilizando PostgreSQL o DBeaver.
3. Ejecutar el archivo `retail_project.sql`.
4. Verificar los resultados mediante las consultas SELECT incluidas en el script.

## Tecnologías utilizadas

- PostgreSQL
- DBeaver
- SQL
